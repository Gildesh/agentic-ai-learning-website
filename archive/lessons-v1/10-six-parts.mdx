You have met the pieces in stories. This lesson puts labels on them and asks you to diagnose by the failure, not by the slogan. The work is still Sam's Sunday study digest. The labels are the six parts of a loop. A good sentence at the top of the desk does not replace the other five.

## The six, and the failure each one prevents

Heartbeat. Something starts the next beat: a finger, until done, a clock, or a doorbell. If this is missing, nothing starts. Sunday arrives and the folder is quiet, which you already watched happen while Sam slept.

Separate working folder. This Sunday's draft is written in its own place, not on top of last Sunday's file. If this is missing, two runs overwrite one file. The second Sunday deletes the first Sunday's brief by saving into the same name. Sam wanted a history. Sam has a single file that only remembers the latest writer.

Saved instructions. Sam's format is written once: one page, one sentence per source, a gap line when a link fails, the date as 12 May. Each run reads that card. If this is missing, every run re-guesses the format. One week uses bullets. The next week uses a letter to the teacher. The finish line is reinvented from the model's habits instead of from Sam's card.

Maker and checker. One pass writes the draft. A different pass grades it against the finish line. If this is missing, the writer grades itself. You felt that when the same helper said "Done!" with the gap line absent. The full split is the next lesson but one. The label belongs here so the picture is complete. Do not invent a scoring product. The failure is enough: the writer marked its own work fine.

Connector. A permitted plug into a real app. For Sam, the plug is open page and save note. People who build these plugs often call the common shape MCP. That is the name, once. You do not need the plumbing. If the connector is missing, the helper can talk about the web and cannot open a page. You get transcript A from the tool lesson: a summary with no result paper.

Spine. A saved note, outside the model, of what is done, what is next, and what is waiting on a person. If this is missing, next Sunday is the first Sunday. The helper opens link 3 again as if Sam had never accepted a two-source brief. The shape of that note is a later lesson. The failure is this lesson's job: no note, no continuity.

The picture stacks the six labels under the Sunday digest. Each one carries an "if this is missing" line. Use the picture as a diagnosis chart. Read the mess first. Then point at the label whose missing-line matches the mess.

## Two messes

Mess one. Two Sundays run, and the second save replaces the first brief. The links were opened. The prose was fine. The history is gone. Which part is missing? The separate working folder. A heartbeat was present, because the second Sunday happened. Tools were present, because a file was saved. The save landed on the only file. The folder was not separate.

Mess two. The helper has tools. It can open pages. It has no note of last Sunday. It treats every link as new, including the library page Sam already gave up on. Which part is missing? The spine. The connector works. The memory between runs does not. Do not "fix" this by pasting the entire old chat and hoping. The missing object is a short note written to be read first. You will see the lines of that note soon. Naming the hole is today's skill.

## A prompt is one paper

Sam will be tempted to write a longer instruction that says "remember last week, do not overwrite files, check your work, and be careful." That paragraph is still one paper on the desk. It does not start the clock. It does not create a second folder. It does not hire a second grader. It does not plug in a tool that was never attached. It does not leave a note in the drawer after the desk is swept.

A good prompt is the saved instructions, or part of them. It is part number three. Calling it the whole loop is how the other failures stay invisible. When something breaks, ask which missing-line you are looking at. Then you know whether to write a clearer card, or to build a different part.

Leave the rubric's exact bars for the checker lesson. Leave the eight lines of the note for the spine lesson. If you can point at the failure and say the part, this picture has done its work.

## Diagnose three Sundays

Sunday A produces nothing. The folder is untouched at noon. The missing part is the heartbeat. Do not rewrite the format card. Nothing read it.

Sunday B produces a brief, and last week's brief is gone from its old place. The missing part is the separate working folder. The words can be lovely and the history can still be destroyed.

Sunday C produces a brief in a new file, with tools that clearly returned page text, and it argues again about link 3, which Sam already accepted as a gap. The missing part is the spine. The connector worked. The note did not.

Say the three diagnoses out loud until the repairs stop collapsing into "write a better prompt." A better prompt would be a change to saved instructions, which is a fourth Sunday: the format drifts from bullets to a letter even though files, tools, and the clock are fine. Four different messes, four different parts. If you can tell them apart on paper, the picture is yours.

<Misconception>

A good prompt replaces the other five.

</Misconception>

A prompt can hold the format and the finish line. It cannot be the clock, the second folder, the other grader, the plug, or the note that survives a new chat. Those are different parts. A stronger sentence does not grow them.

The separate working folder. The second run needed its own place to write, so last Sunday's brief would still be there.

</Check>

The spine. Tools can open pages and still have no record of what Sam already accepted.

Add Sunday D in the margin. The brief is saved in a new file, the clock ran, the note of last week was read, and the format changed from one sentence per source into a cheerful essay. The missing part is saved instructions. The other parts can be healthy while the format drifts. If your repair for every Sunday is a longer essay of advice, you are treating every missing part as if it were this one. Say the part first. Then decide whether any sentence needs to change at all.

<Recap>

- Six parts: heartbeat, separate working folder, saved instructions, maker and checker, connector, spine.
- Diagnose from the failure: nothing starts, files collide, the format drifts, the writer grades itself, talk without opening, or every Sunday is the first.
- MCP is only the common name for a connector plug.
- A prompt is the instructions. It is not the other five parts.

</Recap>
