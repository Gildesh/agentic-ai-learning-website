Sam wants a study brief and meets three helpers in one afternoon. They all speak in text. They are not the same kind of help. If Sam picks the wrong one, the brief is either impossible or absurdly expensive for a job a single fixed step could have done.

## The three meetings

The first helper is the chat Sam already knows. Sam asks, "What does spaced repetition mean?" The helper answers and waits. Sam asks a follow-up. It answers and waits again. Nothing starts until Sam types. Nothing is opened. The desk holds the conversation, and the model continues it. This is a chat: a conversation that waits for the person every turn.

The second helper is a small habit Sam writes on a card and follows by hand, or asks a tool to follow without choosing. The card says: always save the date as 12 May, never as 05/12, and never as May 12th. Every note, every brief, the same shape. There is no moment where the helper looks at the date and decides a different format would be nicer. This is a recipe: steps that never change and never choose.

The third helper is the one Sam actually needs for the links. Three articles are sitting in a list. Someone has to open them, notice that one of them is a broken page, and decide the brief should say so instead of inventing a sentence. The next step depends on what comes back. This is an agent: a model that can use tools and choose the next step. You have not yet seen the tools up close. For now, the mark of an agent is the choice. A chat can talk about choosing. An agent is the case where the next action is selected after looking, and the looking can change the action.

The picture is three columns. Chat: "What does this word mean?" Pick this when you want an answer and you will ask the next question. Recipe: "Always save the date as 12 May." Pick this when the steps never change and never choose. Agent: "Decide which of these links is worth opening." Pick this when the next step depends on what comes back.

## How to classify without a debate

Take the task as a sentence and ask two questions in order.

First: does any step depend on news that arrives in the middle? If the answer is no, you are looking at a chat or a recipe. "Explain this word" is a chat. "Always format the date as 12 May" is a recipe, because the step is the same on every note and it never looks up to pick a different step.

Second: if a step does depend on news, can the helper touch the world, or can it only talk? "Decide which of these three links is worth reading, then say why" is an agent if the helper can open the links and choose from what is inside them. If it only sees the titles and guesses, it is still a chat. The sentence sounded like a decision. The desk never received the pages. Guessing from a title is a continuation, which you already know how to distrust.

Write the classification in four words so you cannot hide inside a paragraph. "Date format: recipe." "Define a term: chat." "Choose among links you can open: agent." "Choose among links you cannot open: chat, and a weak one."

## When an agent is the wrong tool

An agent is the wrong tool when the steps never change. Formatting a date does not get better because something "decides." A recipe is shorter, easier to trust, and it does not spend a turn wondering whether May should sometimes be written out.

An agent is also the wrong tool when a wrong step is costly and nobody checks. Sending the brief to Sam's teacher is costly. A helpful tone is not a check. If nobody is going to look before the send, do not hand the send to a chooser. Keep the chooser on the reading and the drafting, and leave the send for later, when you have a rule about asking a person. You do not need that rule's full shape yet. You need the reflex: cost plus no checker means do not automate the leap.

Sam's brief needs a mix, and the mix is allowed. The date line can be a recipe. The definition of a word inside an article can be a chat, if Sam asks. The choice of what the broken link means for the brief is an agent job, because the next sentence depends on a result. Naming the mix keeps you from calling the whole afternoon "an agent" and then forgetting which part was actually a fixed rule.

## A second afternoon

Sam's friend asks for help with three chores.

Chore one: "Turn my bullet list into numbered steps, every time, in the order I wrote." Recipe. The order is already chosen. Nothing in the middle brings news.

Chore two: "Tell me if this paragraph is rude." Chat. Sam's friend will read the answer and ask again if needed. No page is opened. No file is saved.

Chore three: "Look in the folder. If the homework file is there, summarize it in five lines. If it is missing, say it is missing and stop." Agent. The next sentence depends on what the folder contains. A chat that has not looked in the folder can only invent a summary or admit it has not looked. Inventing is the strawberry problem in a new costume.

A long chat can feel like chore three because it went on for an hour and the topic was complicated. Length is not the mark. The mark is whether a next step was chosen from a result. A long conversation that waits for you every turn is still a chat. People call it an agent because the word sounds more serious. Serious is not a kind of help.

Stay with these three kinds until you can sort a new sentence in under a minute. The later pages will build the agent kind slowly: a finish line, a tool, one beat, a wrapper. They will not be clear if every task is already "just an agent" in your notes.

## Sort a morning in four lines

Write four chores from your own week, each as one sentence. Beside each, write chat, recipe, or agent, and the reason in under ten words. A sample morning: "define this term" is a chat, because you will ask the next question. "File every reading note under the date 12 May" is a recipe, because the step never chooses. "If the link opens, quote one sentence; if it fails, write that it failed" is an agent, because the next line depends on news. "Send the note to my teacher without me" is an agent-shaped wish you should reject for now, because a wrong send is costly and nobody is checking.

The fourth line matters as much as the correct labels. This course will eventually put a gate in front of that send. Today, the skill is to notice the cost and refuse the chooser. If your four lines are all labeled agent, look again. Most weeks contain recipes people have dressed up as decisions. A sort that always sorts the same way is a recipe even if a shiny screen calls it smart.

<Misconception>

A long chat is an agent.

</Misconception>

A chat waits for you. It can be long, clever, and still unable to choose a next step from a tool result. Length is not a kind. The kind is whether the steps are fixed, whether the helper only talks, or whether it chooses after something comes back.

<Recap>

- A chat answers and waits for the next question.
- A recipe runs steps that never change and never choose.
- An agent chooses the next step, and it needs a way to touch the world before that choice is real.
- Use a recipe when the steps are fixed. Refuse an agent when a wrong step is costly and nobody checks.

</Recap>
