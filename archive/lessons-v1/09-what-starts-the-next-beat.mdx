Sunday arrives. Sam is asleep. The digest does not exist. The links are in a folder. The finish line is written. The wrapper would allow open page and save note, and would stop before email. None of that runs, because nobody pressed go. Sam was the only starter, and Sam is in bed.

A beat, you already know, is one pass: see the desk, choose, act, read what came back. A loop is a system that starts beats, checks them, records them, and can start again. The piece that starts the next beat is the heartbeat. If the heartbeat is you, typing "do it again," then you have not left the chat. You have a habit.

## Four starters, one digest

The work can stay the same. The starter changes. There are four.

First: Sam presses go while watching. Sam is at the laptop, types "make the Sunday brief," and stays for the beats. This is honest and small. It is how you walked the one beat by hand. The heartbeat is a finger on a button. Close the laptop and the next beat does not happen, because the finger left.

Second: keep going until the finish line is true. The starter is the line itself, plus a rule that another try begins when the line is still false. You will spend a whole lesson on this shape. For now, learn its name as a heartbeat: until done. It is different from a clock. It does not care that it is Sunday. It cares that the checklist is unmet, and it is willing to try again. It still needs a limit so it cannot try forever. That limit waits with the full lesson.

Third: a clock. Sunday at 09:00 the digest starts, whether Sam is awake or not. The laptop can be closed if the clock lives somewhere that stays awake. You do not need the name of a scheduling product. You need the picture. An alarm exists outside the chat. When it rings, a fresh beat begins with the desk prepared: finish line, permissions, and a note if one was saved. The chat box cannot be this alarm. A chat box waits. It has no heartbeat of its own.

Fourth: a doorbell. A new link lands in a folder, and that arrival starts a beat. Nothing happens on empty days. The folder is the button. This fits a chore that should run when news appears, not because a weekday turned over.

## Who is the heartbeat?

Ask one question of any setup. If every person walked away and every laptop lid closed, would another beat still begin?

If the digest still appears on Sunday, the starter is the clock. Someone built an alarm outside the chat. You may not know their software. You know the kind.

If Sam types "do it again" each week, Sam is the heartbeat. The typing can be skillful. It is still Sam. Calling it a loop because it happened four Sundays in a row is a diary, not a heartbeat. A diary depends on the writer waking up.

If a beat begins only while a window is open and a person is watching a timer they started, the finger is still nearby. The moment the window closes, the timer's home is gone. Say that in the plain way: the starter lived inside the visit, so the visit was the heartbeat.

The chat box is the trap, because it feels like the whole product. You can design a beautiful desk inside a chat. You can walk a beat there. You cannot leave a chat to ring on Sunday. The box is built to wait for the next human line. Waiting is the opposite of a heartbeat.

When you label a system, use one of the four words: finger, until done, clock, doorbell. If you cannot pick, you do not yet know what starts the work. Not knowing is allowed. Pretending the chat will start itself is how Sunday morning stays empty.

## Label four real weeks

Think of a chore you repeat. Write it once. Then write four versions that differ only in the starter.

Finger: you open a chat every time and type the chore. Clock: it begins at a named hour even if you are out. Doorbell: it begins when a file or a message arrives, and it stays quiet when nothing arrives. Until done: it keeps taking another beat until a finish line is true or a small try limit hits, and you are not the one saying "again."

Circle the version you actually have today. For most people the circle lands on the finger. That is a fine place to be while you are learning. The mistake is to describe the finger with the words of a clock. "I do it every Sunday" can still mean "I type every Sunday." The lid-closed test is the honest one. If a closed laptop and an empty room produce no beat, you are the heartbeat. Say so. The next lessons will add parts around a real starter. They cannot add a starter you are unwilling to name.

<Misconception>

If I re-prompt it every Sunday, I have built a loop.

</Misconception>

Re-prompting means you are the heartbeat. A loop's heartbeat starts the next beat when you are not typing. A weekly habit can be good. It is still you.

<Check question="The laptop is closed and the digest still appears on Sunday. Which starter is that?">

The clock. Something outside the chat rings at a time, and a beat begins without Sam typing and without the laptop open.

</Check>

<Check question="Sam types do it again each week. Who is the heartbeat?">

Sam. The week can be regular and the starter can still be a person at a keyboard.

</Check>

Write the lid-closed answer on the same page as the chore. "If I am away, this does not run" is a complete answer for a finger. You can live with that answer for a long time. What you should not write is "it kind of runs itself" when the truth is that you type. Kind-of is how a chat gets described as a loop. The four names exist so kind-of has nowhere to sit. Pick a name. If the name is finger, own it until you build a different starter on purpose.

If you want one sentence for a friend, use the lid. "A loop starts when I am not typing. If it only starts when I type, I am the heartbeat." You can add which of the four you are aiming at later. You do not need to pretend you have a clock in order to sound advanced. Naming the finger clearly is more advanced than borrowing the word loop for a habit. The word will fit when the lid test passes.

<Recap>

- A heartbeat is whatever starts the next beat.
- Four starters: you press go, until the finish line is true, a clock, or a doorbell.
- A chat box waits. It does not ring on Sunday by itself.
- If you must type "again," you are still the starter.

</Recap>
