# From generative AI to shipping real software

A 150-page course for a smart beginner. Read it at [agenticailearningwebsite.vercel.app](https://agenticailearningwebsite.vercel.app).

## Commands

```bash
npm run dev
npm run check:course
npm run build
```

`npm run dev` starts the site locally. `npm run check:course` checks that all 150 pages, figures, and glossary terms are in place. `npm run build` is the production build. GitHub Actions runs the course check and `npm run lint` on every push and pull request.
