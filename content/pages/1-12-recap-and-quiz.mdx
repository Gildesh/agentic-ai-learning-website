## The idea

An <Term id="llm">LLM</Term> predicts the next token. It does not count letters unless you force the letters into view or hand the count to code. A <Term id="hallucination">hallucination</Term> is a specific claim with no source in the prompt or in a tool result. Asking "are you sure?" produces another prediction.

Training updates weights. A chat does not. A new chat knows a fact only if the app pastes it: the transcript, a saved note, or a retrieval hit. The context window is that one request. Text that fell out of the window is gone for that call.

Text, image, and audio are different artifacts. Code is text. A code model does not execute. A tool does.

As of September 2026, the model id is the string on the request. Prices on the previous page are per million tokens, and output costs more than input on every row quoted there. A chat app hides the HTTP request. An API key is a secret. An agent is a loop of tool calls. You grade the artifacts.

## Real example

One page, five checks, before the quiz. Say each one out loud in a sentence of your own.

1. Strawberry has three r's. A confident "two" was a token guess.
2. Paper Lantern survives in a new chat only if some note was pasted in.
3. `claude-sonnet-5-5` is not the same window as Haiku 4.5.
4. A 600-word essay is output tokens.
5. "Tests passed" needs the command output.
