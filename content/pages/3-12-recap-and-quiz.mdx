<Hook>

You can sit down at Cursor, VS Code, Antigravity, or Claude Code and ask the same three questions. What did it read, what is the diff, and what did the command print? The product chrome is optional. Those three are not.

</Hook>

## The idea

An AI coding tool is an agent loop: read a file, edit a file, run a command. The chat text is the transcript. The edit is a <Term id="diff">diff</Term>. The result is command output.

Editor agents sit with the file. Terminal agents sit with the shell. Use the one where the evidence already is. Do not let two of them write the same folder.

VS Code documents chat, inline chat, and inline suggestions, and it can use extensions and a model key you bring. Cursor documents project rules in `.cursor/rules`, `AGENTS.md`, and hooks in `hooks.json`, with Tab as the inline-completion surface. Antigravity's docs list the IDE, the CLI, and Antigravity 2.0. Claude Code reads `CLAUDE.md` at session start and can run a subagent with its own tools and context window.

The model picker selects an LLM. Map it to a model id before you compare cost or context length. Plan prices stay on the vendor's page.

<Term id="git">Git</Term> is the undo. Commit a clean snapshot, open one project, let the agent edit, read every minus and plus, run the check, then commit. `git restore` throws away uncommitted work. Use it on purpose.

## Real example

Five lines that match the quiz.

1. A summary is not a diff.
2. One writer in the folder.
3. `CLAUDE.md` is read at session start.
4. A plus line you did not request fails the review.
5. Commit before the agent starts, not after an unread edit.
