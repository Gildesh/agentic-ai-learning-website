## The idea

Google Antigravity's getting-started page, checked for this course in September 2026, lists three surfaces: Antigravity 2.0, the Antigravity CLI, and the Antigravity IDE. The CLI guide on that site describes installing a client, launching a terminal interface, and working with autonomous agents. That is the terminal agent from the previous pages, under this product's name.

The IDE product page describes an editor. It names Tab, Command, and Agents. Tab is autocompletion. Command is natural-language edits in the editor. Agents are the configurable agent. The same page says agents can operate across the editor, the terminal, and the browser, and that you manage tasks rather than individual tool calls. It also says you can leave comments on an artifact to guide the agent.

An artifact here is the thing you review: a plan, a diff, a result. Commenting on it is a second prompt aimed at that artifact, which is the revision habit from Part 2. You still want the underlying <Term id="tool-call">tool call</Term> when something claims to have run. A task summary without a command log is not a result, in this product or any other.

This course does not rank Antigravity against Cursor or VS Code. It does not copy a price. The pages to trust are the [getting started guide](https://antigravity.google/docs/getting-started/) and the [IDE product page](https://antigravity.google/product/antigravity-ide/). If a blog uses a different product split, the docs win.

Use the IDE when you want Tab and the file on screen. Use the CLI when you are already in a terminal and want an <Term id="agent">agent</Term> there. Antigravity 2.0 is the desktop app those docs list. Open the getting-started page for the install steps of the surface you picked, and follow that page rather than a mix of all three.

## Real example

A note you can fill while the docs are open:

```
Surface I will use:
What the docs call the agent there:
Where a finished task shows up (diff, artifact, or terminal log):
```

If you cannot fill the third line from the page, you do not yet know how you will review the work. Find that sentence before you install a second surface.

<TryIt minutes={5}>

Open the getting-started page and write the three surface names exactly as they appear. Then open the IDE page and write the words it uses for Tab and for agents. You are building a glossary of this product's screen, not memorizing a ranking.

</TryIt>

<Mistake>

Following a screenshot tour that mixes the CLI and the IDE without saying which one. A terminal-only instruction will not match an editor button. Name the surface in your own note before you follow a step.

</Mistake>
