<Hook>

You tell an agent "make a page that lists paperback titles" and a page appears. You have not opened the file. You click the page, dislike the heading, and say "make the heading smaller." That loop has a name. The name is not a method with a checklist. It is a description of not reading the code.

</Hook>

## The idea

<Term id="vibe-coding">Vibe coding</Term> is building by describing what you want, running it, and reacting to what you see. Andrej Karpathy posted the phrase on X on 2 February 2025. The post is still at [this status](https://x.com/karpathy/status/1886192184808149383). He described giving in to the vibes and forgetting that the code even exists. People use the phrase for that style: an <Term id="agent">agent</Term> writes the files, you steer from the screen or the error, and you may never read the function.

The phrase is useful because it is honest about the skip. You are not "almost programming." You are declining to inspect the artifact and judging the run instead. For a weekend demo in a folder you can delete, that can be the right trade. The screen is the product of the hour. The files are disposable.

The skip becomes a defect when someone else will rely on the folder, or when money, passwords, or stored rows are involved. Forgetting the code exists does not make the code harmless. It means you cannot tell a success message painted in HTML from a payment that actually settled. Later pages in this part keep the loop and put the reading back at the moment the folder has to survive.

Do not treat the phrase as an insult or as a rank. It names a speed. Part 3 already told you the tool reads, edits, and runs. Vibe coding is what you are doing when you only watch the run.

## Real example

Two notes on the same afternoon.

```
Folder: scratch-list
Ask: a page of three paperback titles
I will not read the file. I will delete the folder tonight.
```

```
Folder: paper-lantern
Ask: checkout
I will read the handler before any card data is involved.
```

The first note is vibe coding on purpose. The second note is a refusal to use that skip on a payment path. Both can use the same agent.

Open Karpathy's post and write one sentence in your own words for what he is willing to forget. Then write whether your current project is a scratch folder or a folder you would be ashamed to delete. That second sentence decides how much of this part you are allowed to skip.

</TryIt>

<Mistake>

Hearing "vibe coding" as permission to ship. The original description is about forgetting the code during a fast experiment. Shipping is the opposite: someone else hits the path you did not read.

</Mistake>
