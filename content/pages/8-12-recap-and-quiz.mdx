## The idea

Secrets live in `.env` and in the host's environment. `.env.example` is the committed list of names. A key that reached git is already published. Rotate it.

Authentication answers who is calling: a session cookie, a signed JWT, an OAuth code exchanged on the server, or a single-use magic link. The user id does not come from the body. Authorization answers whether that caller may touch this row. The owner column is the comparison. OWASP Top 10:2025 puts broken access control first and injection at A05.

Every input is checked on the server. SQL takes parameters. HTTPS encrypts the connection. CORS is a browser rule, not the owner check. Session cookies are `HttpOnly`, `Secure`, and `SameSite`.

For agents, the 2026 LLM list names prompt injection, sensitive information disclosure, and excessive agency. Do not put `.env` in the prompt. Do not give a docs task a payment tool.

Stripe Checkout and Razorpay Standard Checkout collect the card. Your server creates the session or the order with the secret key and verifies the result. A webhook is accepted only after the signature matches the raw body. Idempotency means a repeated event id fulfills once. Test mode uses test keys and Stripe's test card `4242424242424242`. Live mode uses live keys and the live webhook secret. The success URL is not proof of payment.
