## The idea

A framework exists so a named component is the one place a piece of UI lives. In React, a component is a function that returns elements. Props are what the parent passes in. State is what this component owns. A React hook such as `useState` or `useEffect` runs in a Client Component. It is not an agent hook.

Next.js with the App Router maps `app/.../page.tsx` to a URL and `layout.tsx` to shared UI. In this version, `params` is a promise. Pages are Server Components unless the file starts with `'use client'`. The server file may hold a secret and a database read. The client file may hold a click. Pass props down. Do not pass the database client.

`loading.tsx` shows while a page segment waits. A layout that reads cookies does not use that fallback. A Server Function behind a form is invoked with POST, including by someone who skips the button, so it checks the session first.

Angular components are classes with `@Component`. You read a signal by calling it. Inputs are the props. Vue puts template, script, and style in a `.vue` file and compiles it. Svelte compiles a `.svelte` file to JavaScript, and SvelteKit is the app framework around it. Pick one. This course stays on Next.js.
