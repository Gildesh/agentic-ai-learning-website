<Hook>

You can now point at the file that holds a rule. If you cannot, the rule is still a chat. The quiz is that distinction, plus the filenames the tools actually read.

</Hook>

## The idea

Agents do not keep your corrections in their weights. A written instruction is how the next request still contains the rule. Cursor documents project rules in `.cursor/rules` and names `AGENTS.md` as a plain-markdown alternative. Claude Code reads `CLAUDE.md` at the start of a session. One copy of a rule. A second copy will drift.

Rules hold standing constraints and a pointer to the spec. They do not hold secrets, today's traceback, or one-off tasks. A line you could not use to reject a diff does not belong.

A <Term id="skill">skill</Term> is one repeatable job in `SKILL.md`. Cursor requires `name` and `description`, and `name` must match the folder. `disable-model-invocation: true` loads that skill when you type `/skill-name`, not on every turn. Claude Code also uses `SKILL.md`, and the directory or the frontmatter name becomes the command. Check the live docs for the directory.

A <Term id="spec">spec</Term> at `docs/SPEC.md` is this course's source of truth for behavior. Vendors do not load that path unless you tell them to. A task card is one spec line, the files allowed, and a check. When instructions conflict, delete the false line before you rerun the agent. The starter kit is `AGENTS.md`, `docs/SPEC.md`, and one `SKILL.md`.

## Real example

Five lines that match the quiz.

1. A finished chat is not a rules file.
2. `CLAUDE.md` and `AGENTS.md` are different contracts.
3. `SKILL.md` is one job, not every rule.
4. The spec can fail a test a stranger could run.
5. Two disagreeing lines get edited before the next run.

<TryIt minutes={5}>

Answer the quiz. Then open one instruction file and find a line you could not use to reject a diff. Cut it or move it to the spec. If every line survives, write the task card for the next change with Job, Files, and Done filled in.

</TryIt>

<Mistake>

Memorizing the three filenames and skipping the spec. `CLAUDE.md`, `AGENTS.md`, and `SKILL.md` only help if a testable sentence exists somewhere they point. A filename with vague advice is a labeled empty box.

</Mistake>
