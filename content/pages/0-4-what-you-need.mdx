<Hook>

You do not need a paid plan, a new laptop, or every coding tool installed. You need a machine you can type on, a current browser, a GitHub account, and one place to paste a prompt and read the reply.

</Hook>

## The idea

Use the laptop you already have. The pages that show code use a browser width and a normal keyboard. A current version of Chrome, Edge, Firefox, or Safari is enough. The site you are reading stores progress in this browser, not in an account of ours.

Create a <Term id="repository">repository</Term> host account on GitHub if you do not have one. As of September 2026, signing up at [github.com/signup](https://github.com/signup) does not require a credit card. A repository is the project folder Git tracks. Later pages use it as the undo button and as the place checks run. You will not create the project repository on this page. You only need to be able to sign in.

Open one AI chat in the browser. Use a free tier if the product offers one, and do not enter a card for this course. Part 1 names the model families. Part 3 names the coding tools: VS Code, Cursor, Google Antigravity, and Claude Code. Those tools are where an <Term id="agent">agent</Term> edits files. You do not need all four. You need one chat now so the prompting pages have somewhere to land. When a later page needs a specific tool, it says so, and it tells you what the free path can and cannot do. If a price or a limit is not on that page, it was not verified, and you should read the vendor's pricing page rather than trust a memory.

## A setup that is enough

This is the whole kit for Part 0 and Part 1:

- The laptop you are using now.
- The browser you are reading this in.
- A GitHub sign-in.
- One AI chat, free tier, no card on file.

Node, Python, and a database come in the parts that use them. Installing them early adds errors that have nothing to do with the idea on the page.

<TryIt>

Open [https://github.com/signup](https://github.com/signup) and create an account, or sign in if you already have one. Stop when you can see your dashboard. Then open one AI chat you can use without paying, send the sentence "Reply with the single word ready", and confirm you get a reply. That is the whole setup.

</TryIt>

<Mistake>

Buying a subscription before you have a spec. Paid limits and model names change monthly. This course will tell you when a paid feature is actually required. Until that sentence appears, a free chat and a free GitHub account are the tools the pages assume.
</Mistake>
